# ManualDock v0.2.2 功能状态

本产品提供目录发现与核验、逐章保存和每三分钟恢复重试、可选导航轮换。实现这些机制不等于已经证明所有设备的整册目录完整或会话不会退出。当前通用适配依据来自模拟页面和隔离浏览器测试，没有其他真实设备的兼容性结论。

| 核验项 | 已实现的机制 | 仍需区分的边界 |
|---|---|---|
| 目录核验 | 稳定章节编号去重；章节到达与正文加载验证；重复正文待核对；提示未加载分支、歧义节点、虚拟目录和扫描上限 | 没有独立、权威的完整目录作对账。发现并处理全部队列，不等于整个网站的手册都已发现 |
| 断点重连 | 逐章本地保存；可重试网络、登录及加载错误每 3 分钟尝试继续；恢复重试状态持久化；手动暂停取消自动继续 | 不自动登录。控制页关闭时不执行重试；权限失效或源标签页关闭时需要重新授权。恢复前验证两章，已保存整册不会从头采集 |
| 后台导航 | 从页面导航结构和当前菜单生成候选；可手动校准；预览、试运行、保存后启动；默认每 60 秒轮换；最近点击与累计次数可见 | 默认关闭。无可靠导航时需点选；不新增、删除对象或提交配置；没有设备侧会话续期成功的验证，点击成功不保证不退出 |
| 多手册并行 | 锁按标签页与任务分别持有；在各自手册标签页点击扩展可同时跑两个任务；“已保存”汇总全部任务的进度、状态与最近保存时间 | 同一标签页不能同时采集两本手册，也不能边轮换边采集。状态按最近保存判断，控制页关闭超过两分钟不再显示为运行中 |
| 已保存管理 | 显示产品版本、来源、类型、已保存章数、状态与创建/更新时间；可打开、导出 JSON、删除（二次确认，保留识别规则） | 删除不可撤销；未导出就没有副本。“正在采集”不是进程级心跳，崩溃后可能残留“已停止，无新的保存” |

## 如何理解恢复

例如已保存 200 章、下一章遇到断网，工具保留这 200 章，安排三分钟后的尝试；连接恢复且两章验证通过后，再处理未完成章节。若返回登录页，用户仍需在原网站登录。手动暂停表示用户要停止，工具不会自行再启动。

重试针对暂时中断。重复正文、定位歧义、规则失效等问题需要检查页面或重新校准，不能通过无限重试把它们伪装成采集成功。

## 如何理解导航识别

工具根据页面容器、导航角色、可见标签和可定位目标生成候选，而不是固定三个菜单词。预览与试运行用于确认实际点到的是合适的导航。如果网页没有足够的结构线索，点选校准仍然必要。

创建再删除对象不属于轮换能力：创建成功是一次真实配置写入，删除前断线可能留下对象；创建校验失败也不能证明会话续期。本产品没有执行这类写操作。

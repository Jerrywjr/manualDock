# 功能与限制

当前维护版本和未关闭问题以 [project-status.md](project-status.md) 为准；下方版本段落保留历史，不表示已现场验收。

| 能力             | 已实现的行为                                                                                           | 实际边界                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 单工作台、多来源 | 已知 adocs/cdocs 文档和 framework 管理入口自动确定用途，其他地址按当前栏目逐页连接；两类页面各自选择   | 最多 8 个来源；同一源标签页和同一任务均互斥。刷新或关闭工作台不停止任务；保留来源标签页和浏览器 |
| 固定界面         | 操作分区、目录与资料库分页、固定导出栏                                                                 | 正文和诊断预览内部滚动；长文字会截断，可悬停查看                                                |
| 快速发现目录     | 来源独立扫描；读取已加载项，按需加载缺失分支；复用未删除的任务身份                                     | 虚拟列表、未加载分支、跨域框架可能不完整，不以数量推断整册完整                                  |
| 手动校准         | 连接后即可点选目录与正文；自动识别失败保留候选规则供校准                                               | 仍需验证两个不同章节；候选规则未确认前不覆盖旧存档                                              |
| 采集与恢复       | 首次整本验证两章；Ext 树目录续采重新核对范围；局部章节失败隔离；连接类故障递增重试，保存进度后重置间隔 | 不自动登录；浏览器休眠可能延后重试；源页面重新授权可能仍需点击扩展                              |
| 已保存管理       | 搜索、分页、类型筛选、查看、导出、删除，运行任务删除前必须暂停                                         | 删除没有撤销；重新识别建立新任务，旧正文只能通过用户导出的档案恢复                              |
| 同步与档案恢复   | 本机数据库修订校验与更新通知；JSON 恢复补齐缺页、冲突保留本机                                          | 没有跨设备云同步；导入的内容不作为本次真实采集证明                                              |
| 规范文件         | Swagger 2.0、OpenAPI 3.0/3.1 的 JSON/YAML                                                              | 不执行接口；不自动抓取外部引用                                                                  |
| 导航轮换         | 扩展后台按管理页独立调度；栏目切换、文档采集不停止轮换；刷新后重新校验并接续                           | 手动停止或关闭来源页才停止；页面越界或点击结果丢失则停止；后台计时可能延后，点击不证明会话续期  |

例如两个来源分别导入接口手册与命令手册，第一个需要重新登录时只暂停第一个。已保存 200 章后中断，续采使用原任务和已存正文；若导入较旧的 JSON 档案，本机已有章节不会被旧内容覆盖。测试范围见 [验证说明](validation.md)。

0.2.12 移除连接用途和历史识别配置下拉框，保留任务内部校准与存档。采集按钮旁显示停止原因；任务级故障后先恢复来源，恢复失败不推进章节，成功后重试未保存的中断章节。此流程的本地回归不等于真实设备整册已验证。

0.3.0 在续采前检查目录、正文和框架定位；明确显示失效区域及匹配数量。缺失区域经旧队列全部章节核对和两章正文验证后，可在原任务内修复；歧义、未知章节或范围变化不会自动接纳。刷新后位于其他章节的旧任务，也需只读证明该章节属于原队列才能接回。后台修复会同步未编辑的界面字段，手动校准及部分样例草稿仍保留。实际 API 设备的完整采集仍需现场验收。

0.3.1 修复将多个 Ext 树根误判为定位歧义的问题。目录配置可选择一个导航容器或多个树根；扫描、展开、手选样例、点击及当前章验证使用相同范围。五个树根不是错误，但相同章节路径指向多个节点时仍拒绝采集。旧 Ext 任务续采重新核对全部原章节，多根目录验证首末两章，并在换章后再检查完整目录；自动更换目录选择器时，不接受比原任务更大的章节集合。原任务编号、章节键与已保存正文保留。本地五根目录测试不等于实际设备验证。

0.3.2 根据用户提供的实际 DOM 结构，区分一个 UL 目录与四个 DIV 参数网格，避免把共享 `.x-tree-root-ct` 的正文表格当成目录。新识别绑定独立导航区域；多个互不相属的目录不自动合并，未知正文树仍需校准。旧宽泛绑定续采仍须核对完整原队列和样例，保留原任务与正文。显式唯一正文中的可见 Ext 参数列和行进入提取及就绪检查；隐藏请求／返回示例仍不自动展开。未编辑的失败重扫可以重新检查并继续，编辑过的候选不能借用旧验证。设备端整本采集仍待验收。

## 0.3.4 正文折叠采集

新增采集前正文展开，支持已观察到的 Ext 参数子树及 `af-api-panel` 请求／成功／失败返回样例，等待子表和样例实际显示后提取；展开失败会报告，不将已知不完整章节记为成功。保留嵌套参数表、分隔相邻请求代码块，忽略树控制图标。此行为替代 0.3.2 的“隐藏样例不自动展开”，不修改目录扫描、连接和轮换。

两份用户保存网页离线核对分别保留 73、79 行参数，各 3 个完整样例。验证使用真实保存的 DOM，但点击事件为模拟，附带脚本/样式是登录页响应，设备实际点击及整本采集尚待现场验证；不代表任意网站折叠控件均已支持。

## 0.3.6–0.3.7 的边界记录

正文读取入口自身强制展开并检查内部样例；预览不点击、不作为可保存结果。已知空样例可经确认重试，未知弹窗无完整性保证。0.3.7 将导出和资料库展示拆为独立模块，保持交互和输出格式。模块、版本、公开文件清单可自动检查，实际设备漏采和 Windows 验收仍未关闭。

## 0.3.8 正文展开预算

正文展开取消点击总次数上限，总预算为 60 秒；换章的 45 秒计时不包含正文展开耗时。单项 2 秒等待、同一控件重复出现保护、章节证明和最终完整性检查保留；目录扫描仍沿用原等待限制。中文代码注释与使用说明解释采集链路。该修改不保证晚加载、再次折叠或未知控件问题已解决，设备完整性仍需现场复验。

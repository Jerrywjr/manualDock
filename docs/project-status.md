## 接手时先做什么

先核对 `git status --short` 和版本，不覆盖未提交改动。按上表问题寻找证据和关闭条件，再按 [modules.json](modules.json) 找源码和测试。只运行与当前授权有关的检查。完成后更新本页的状态、命令和限制；保留失败证据，不能仅在对话里声称完成。需要设备登录时由用户操作，插件不会代连 VPN、登录或绕过证书。

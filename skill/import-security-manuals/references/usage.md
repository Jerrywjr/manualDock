# ManualDock 配套使用指引

本指引随 0.3.8 更新。源码维护者先读仓库根目录的 [当前状态](../../../docs/project-status.md)、[维护边界](../../../AGENTS.md) 和 [模块索引](../../../docs/architecture.md)。单独安装 Skill 不保证这些仓库文档同时存在，可查看 [GitHub 当前状态](https://github.com/Jerrywjr/manualDock/blob/main/docs/project-status.md)。详细操作以仓库 [使用说明](../../../使用说明.md) 为准，不能用旧版界面步骤恢复已删除功能。

## 安装、连接与采集

在 Chrome 扩展管理页加载仓库 `extension/`；单独 Skill 使用 `assets/extension/`。扩展管理页重新加载才会重启后台代码，刷新控制页不是升级。Windows Chrome 使用相同加载方式，但 Windows 完整流程尚未验收通过；VPN、登录和证书由用户电脑和浏览器负责。

在“菜单轮换”连接管理页，在“采集工作台”或“识别与校准”连接文档页。输入地址后优先复用已打开的同一手册标签，文档连接后进入识别与校准。没有用途下拉框或历史识别配置选择器。最多同时连接 8 个来源，暂停保留连接，移除或关来源标签释放名额，移除不删除已存档案。

先快速识别目录，失败时手动校准目录、正文和两个不同章节，验证后采集。采集在后台按来源独立执行；控制页可刷新或关闭，来源页和浏览器需保留。网络类失败递增重试，登录过期自行在来源登录；手动暂停取消重试。管理页轮换独立运行，点击菜单不证明登录已续期。

## 完整性与恢复

正文展开不限制点击总次数，每章总预算 60 秒；单项仍最多等待 2 秒，同一控件反复出现仍报错。换章的 45 秒计时不包含展开耗时；目录扫描限制不变。放宽预算不能保证内部空样例、晚加载或未知控件已解决。

已发现目录处理完不等于全册完整。逐项核对参数子树、请求样例、成功及失败返回样例；当前自动展开仅适配已确认的正文结构，未知模态弹窗、浮层、虚拟内容没有通用保证。不得点击任意按钮、执行示例接口、读取认证存储以补全文档。

Markdown、离线 HTML、JSON、报告共用同一份保存正文；缺内容先查 JSON 的页面正文。升级不自动重采成功章；已知空样例可点“重试问题项”，经用户确认后成功才替换原文。未知缺漏需另行核对，不能宣称换格式就完整。

“已保存”可搜索、筛选、分页、查看和导出；删除须确认，采集中任务先暂停。JSON 导入补齐缺页，冲突保留本机正文，没有云同步。卸载、清除扩展数据或更换安装身份可能失去本地档案。引用结果须附实际来源及目录路径，规范接口不是已经执行过的请求。
